# Design branches for `/refine spec`

Settle these for a slice that builds or changes what the user sees. Ask as described in `SKILL.md`.

- **Design match:** compare the agreed behaviour with each board and `DESIGN.md`. Ask about each part, state, size, word or value that differs between them, or has no token.
- **Not drawn:** ask about each close, exit, failure, empty state, motion and accessible name that no board draws.
- **Kit pages:** ask which parts are live, what holds a later Spec's place, and what the screen Spec owns (position, timers).
- **Design check:** for a screen in `design/screens.json`, read its percent in the `design-check` artifact of `main`'s last CI run. A new screen has none. Ask how the check sees a timed part.
