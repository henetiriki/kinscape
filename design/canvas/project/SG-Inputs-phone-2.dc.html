Role
Event chips are toggle buttons: button aria-pressed. The set sits in a fieldset with the legend "Event type".
Name

Removable

Keyboard
Tab between chips, Space or Enter toggles.

Button as a link

With an href a button is a link: the same look and states, no underline, and no disabled state, because a link can't be disabled. Use it when pressing goes to another page, like Cancel on a form. Drawn by hand: the design system's Button can't be a link yet.

Measurements

  • Height · M 44 · S 40 inside desktop cards (M 44 on a phone)size.control · size.control-s

  • States · the Button's: hover, focus ring, pressedcolour.brand-hover · colour.brand-pressed · colour.brand-tint
  • Disabled · none: a link is never disabled—
