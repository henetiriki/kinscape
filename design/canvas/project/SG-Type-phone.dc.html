Typography and hierarchy

Three families, each with one job. Bricolage Grotesque for headings, Public Sans for everything you read or click, JetBrains Mono for dates and coordinates.

Rules

  • Line height: 1.1–1.25 for headings, 1.45–1.55 for anything you read in sentences, 1.3–1.4 for single-line UI text.
  • Keep running text under 68 characters a line.
  • Weights: Public Sans 400, 500 and 600 only. Bricolage 500 for page titles, 700 for everything else. No other weights.
  • Never set body text below 12.5px, or map labels below 11px.
  • Sentence case everywhere. Uppercase only for overlines and polity or context labels, always with letter-spacing.
  • JetBrains Mono for anything a person compares digit by digit: dates, coordinates, archive references. Ligatures off.
  • Field text is 16px on phones so the browser doesn't zoom in.
