The 44 round button that opens the account Menu; `expanded` is its open look.

## Props

| Prop | Type | Required | Description |
| --- | --- | --- | --- |
| `expanded` | `boolean` | no |  |
| `initial` | `string` | yes |  |
| `state` | `"active" \| "focus" \| "hover"` | no |  |

The other attributes of its HTML element go to the element.
