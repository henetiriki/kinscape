A checkbox with its label and, under it, an optional description the checkbox points to.

## Props

| Prop | Type | Required | Description |
| --- | --- | --- | --- |
| `description` | `ReactNode` | no | Plain text under the label. It is not a live region. |
| `label` | `ReactNode` | yes |  |
| `plain` | `boolean` | no | The sign-in form: a 15 / 22 label in ink-2 and no description. |
| `size` | `"m"` | no | `m` is a 44 row (Basemap and Pins); the default is 48 (Boundaries). |
| `state` | `"active" \| "focus" \| "hover"` | no |  |

The other attributes of its HTML element go to the element.
