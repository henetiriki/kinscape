One marker for a Place that shows several Pins (PIN-06).

## Design

- **Count marker:** A `--pin` circle with the count marks a Place with two or more Pins on the Map date. Name: "3 Pins".

## Props

| Prop | Type | Required | Description |
| --- | --- | --- | --- |
| `count` | `number` | yes |  |
| `selected` | `boolean` | no |  |
| `state` | `"active" \| "focus" \| "hover"` | no |  |

The other attributes of its HTML element go to the element.
