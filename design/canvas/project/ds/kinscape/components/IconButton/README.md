An action shown only as an icon, such as zoom, close or step, named by its `label`.

## Props

| Prop | Type | Required | Description |
| --- | --- | --- | --- |
| `label` | `string` | yes |  |
| `state` | `"active" \| "focus" \| "hover"` | no |  |

The other attributes of its HTML element go to the element.
