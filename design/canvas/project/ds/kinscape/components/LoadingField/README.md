A field that is still loading: its label over one bar, or over two bars for a text area.

## Props

| Prop | Type | Required | Description |
| --- | --- | --- | --- |
| `label` | `string` | yes |  |
| `widths` | `readonly [number, number] \| readonly [number]` | yes | The width of each bar, top to bottom. One bar stands for an input, two for a text area. |
