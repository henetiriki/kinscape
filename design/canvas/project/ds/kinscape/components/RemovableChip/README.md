A chosen value with a × that removes it.

## Props

| Prop | Type | Required | Description |
| --- | --- | --- | --- |
| `disabled` | `boolean` | no |  |
| `onRemove` | `(() => void)` | no |  |
| `state` | `"active" \| "focus" \| "hover"` | no | Shown on the ×, the control inside. |
| `value` | `string` | yes |  |
