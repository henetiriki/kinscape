The date moves filters, not data

Every dated feature carries from and to as day numbers since 1652-01-01 (open = 999999). Moving the slider calls setFilter on each dated layer, so nothing is fetched while scrubbing (NFR-01). 

const onDate = ['all',
  ['<=', ['get', 'from'], d],
  ['>',  ['get', 'to'],   d]];
for (const id of DATED_LAYERS) map.setFilter(id, onDate);

// pins: range events by from/to, point events by a window
const pinsOn = ['all',
  ['<=', ['get', 'earliest'], d + win],
  ['>=', ['get', 'latest'],   d - win]];

Kept to what MapLibre can draw

  • Flat polygon fills only. No shadows, glows or gradient fills on polygons.
  • The contested hatch is a fill-pattern image added with map.addImage . Pattern colour is fixed in the image, so each hatch colour needs its own image.
  • Halos are blurred circles ( circle-blur ), because circle strokes can't be dashed.
  • Labels use text halos, not background boxes. Contested names are one format expression: the name, then a smaller italic line.
  • Pin glyphs are SDF icons, so icon-color and icon-halo restyle them. The shape shows the event type, so colour is never the only cue (NFR-06).
  • Map text needs glyph PBFs: Public Sans Regular, SemiBold and Italic, built once and served from /fonts/{fontstack}/{range}.pbf .
  • Popup: maplibregl.Popup with className: 'ks-popup' and its own close button. Zoom and fit are a custom IControl.
