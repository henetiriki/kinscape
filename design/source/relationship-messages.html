Relationship messages

Each message shows in an alert at the top of the add and edit dialog. The dialog stays open, keeps the picks and saves nothing.

Reason Message Action
self Refusal
A person can't be their own relative Choose someone else.
None
cycle Refusal
This link isn't possible This would make {name} their own ancestor.
None
biological parents Refusal
Too many biological parents A person has at most two. Choose adoptive or step, or edit a link.
None
duplicate Refusal
These people are already linked They already have this link. Edit it from the list.
None
tree-full Error
Your Tree holds the most links it can Nothing was saved.
None
conflict Error
This link changed while you were editing Nothing was saved. Reload to see the latest version, then make your changes again.
not-found Error
This person or link no longer exists Nothing was saved. It may have been deleted.
Go to People

Any other failed save shows an error toast, “Couldn't save the link. Your picks are still here.”, with “Try again”.
