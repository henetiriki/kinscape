Style guide · 02

Colour

Forest green carries the brand and every interactive thing. Burnt sienna is only for pins. Ratios are WCAG contrast, measured on white unless noted: 4.5 for text, 3 for borders, icons and focus rings.

Brand

Primary actions, links, selection and focus.
brand-900 #163019 · 14.3:1 Pressed buttons and links
brand-800 #1D3E20 · 11.9:1 Hover on buttons and links
brand #264F29 · 9.4:1 Primary buttons, links, focus ring, selected point
brand-100 #E6EEE4 · fill only Selected tab, chip on, pressed secondary
KinScape
icon green #264F29 · 9.4:1 App icon background. Never recolour the icon

Accent

Only for pins and things that mean "a person was here".
pin #9A3B12 · 7.0:1 Pins, clusters, event glyphs
hatch #8B4A1C · map only Contested hatch, at 34% opacity

Interactive

One colour family, so anything green can be clicked.
link #264F29 · 9.4:1 Underlined, 1px, offset 3px
link hover #1D3E20 · 11.9:1 Underline thickens to 2px
focus ring #264F29 · 9.4:1 2px outline, 2px offset, on every focusable thing
focus on dark #FFFFFF · 16.5:1 on ink Focus ring inside dark banners
disabled fill #E2E5DD · fill only Disabled primary buttons
