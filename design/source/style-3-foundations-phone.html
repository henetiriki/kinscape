Spacing, shape, depth, icons, motion

The small set of values every screen is built from.

Spacing

A 4px base. Use these steps and nothing in between.

4px Icon to text, tight pairs
8px Inside controls, between chips
12px Icon gaps, row padding
16px Panel padding on phone
20px Panel and dock padding
24px Between floating elements
32px Between sections
40px Between page blocks
48px Sign-in form padding
64px Page padding on boards

Corner radius

4px Keyboard keys, checkboxes
8px Buttons, fields, segments
12px Panels, dock, popups, dialogs
18px Top of phone sheet
full Chips, Play, avatar, pins

Elevation

Raised Panels, dock, search, cards 0 1px 2px rgb(24 33 27 / 0.08), 0 6px 20px rgb(24 33 27 / 0.12)
Floating Popups, menus 0 1px 2px rgb(24 33 27 / 0.1), 0 10px 30px rgb(24 33 27 / 0.2)
Modal Dialogs, over a scrim 0 10px 40px rgb(24 33 27 / 0.3)

Icons

Outline icons on a 24px grid, 2px stroke for every icon, round caps and joins, drawn in currentColor. Shown at 16, 18 or 20px (24 on the phone layers button). Always aria-hidden ; an icon-only button carries the name, such as "Zoom out", "Show password", "Hide password" or "Sign out".

Motion

  • Hover, press 120ms ease-out Colour and border only
  • Popups, menus 160ms ease-out Fade and 4px rise
  • Phone sheet 240ms ease-out Slides; follows the finger while dragged
  • Changed border 600ms ease-out MAP-11 highlight, then gone
  • Map date change none Redraw at once. Never animate or show a loader (NFR-01)

With prefers-reduced-motion, drop every transition except colour changes, and make Play step without easing.
