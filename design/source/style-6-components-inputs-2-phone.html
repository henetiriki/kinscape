Part 1: buttons, text fields, chips

Tabs

Switch between the Layers and Filters panels. The badge counts the filters that are on.

Measurements

  • Height · 44 on a phone, 40 in the desktop panel size.control · size.control-s
  • Width · Equal: each tab takes half the row (flex: 1) —
  • Bar · Desktop: padding 4, gap 4, 1px line under it · phone: 8 under the row, gap 8 to Close space.4 · space.8 · colour.line
  • Label · 14 / 20 · 600; selected brand-hover on brand-tint, others ink-3 type.label · colour.brand-tint · colour.brand-hover
  • Badge · 20 tall, min-width 20, fully round, brand, white 13.5 / 600; 8 after the label radius.full · colour.brand · type.chip · space.8
  • Radius · 8 radius.control
  • Close · 44 × 44, fully round, ink-3, 20px icon size.touch · radius.full · colour.ink-3

Accessibility

Role
A tablist holding two tab elements with aria-selected, each controlling a tabpanel. The mockups use aria-pressed buttons.
Name
The label plus the count: "Filters, 1 active". The badge alone would read as "Filters 1".
Keyboard
Tab moves into the tablist; Left and Right move between tabs and select them.
Close
aria-label="Close". It closes the sheet and returns focus to the Layers button.

Checkbox field

A checkbox with its name, and on layer rows a line of live detail. Sign-in uses the plain label form.

Measurements

  • Row · min-height 48; the whole row is the label, so all of it is the hit area size.field-l
  • Checkbox · 20 × 20 everywhere, radius 4, 1.5px field-border off, brand fill on size.checkbox · radius.small · colour.field-border · colour.brand
  • Gap · 12 between box and text space.12
  • Name · 14 / 20 · 600 ink type.label
  • Description · 13 / 20 ink-3; live facts, such as pins true on the date type.small · colour.ink-3
  • Label only · 15 / 22 ink-2 type.body · colour.ink-2

Accessibility

Role
A native input type="checkbox" inside its <label>, so clicking the text toggles it.
Name
The name. Tie the description with aria-describedby so it is read after the name.
Live
The description changes with the date ("8 of 214 true on this date"); it is not a live region, so it is read when focused, not on every change.
Keyboard
Tab to reach, Space toggles. Focus ring on the box.

Alerts

For a problem with one part of the screen. Use the untitled form when the one line says it all.

Measurements

  • Padding · 12 · radius 8 space.12 · radius.control
  • Border, fill, text · 1px error-border, error-bg, error text colour.error-border · colour.error-bg · colour.error
  • Icon · 20 filled circle in error-border, white "!", 12 from the text space.12
  • Text · 13 / 20 type.small

Accessibility

Role
role="alert": a failed sign-in is an error. It is announced without moving focus.
Fields
Both fields get aria-invalid="true" and a 2px error-border. The password is cleared, with the helper "Password cleared after a failed attempt."
Icon
aria-hidden; the words carry the meaning.

Dividers

Separate groups that sit close together. Use space first; reach for a line when space alone doesn't read.

Measurements

  • Line · 1px line colour.line
  • "or" · 13 / 20 ink-3, 12 from each line type.small · space.12 · colour.ink-3
  • Footnote · 20 between rule and text; 13 / 20 ink-3 space.20 · type.small

Accessibility

Hairline
Decoration: a span or an hr with aria-hidden, so it isn't read.
"or"
The word is read; the two lines are aria-hidden.
