Inputs and actions

Every button, field, chip, tab and checkbox row the sign-in and map screens use, at the sizes they use them, with their states.

Buttons

Primary for the one action a view is for, secondary for everything else. Pick the height from where the button sits, not from how important it is.

Measurements

  • Height 50 sign-in · 44 panels, dock and Play · 40 inside desktop cards (44 on a phone) · 36 Copy chain size.control-l · size.control · size.control-s · 36: no token
  • Radius 8 · Play fully round (22 on a 44 button) radius.control · radius.full
  • Padding 0 16 everywhere on a phone · 0 16 0 12 Play · 0 12 Copy chain · sign-in buttons fill the form space.16 · space.12 · 14: no token
  • Label 16 / 24 · 600 sign-in · 14 / 20 · 600 elsewhere · 13 / 600 Copy chain type.button · type.button-s · 13/600: no token
  • Icon 16 Play · 14 Copy chain, 8 from the label · Google mark 20, 12 from the label space.8 · space.12
  • Colours Primary: brand, white text. Secondary: white, 1px line-strong (cards) or field-border (panel, popup). Google: white, 1px google-border, google-text colour.brand · colour.line-strong · colour.field-border · colour.google-*
  • Focus 2px outline, 2px outside focus.width · focus.offset · colour.focus-ring

Accessibility

Role
A real button. Sign in is type="submit"; the rest are type="button".
Name
The visible label. Icon-only Play has aria-label="Play through time", which becomes "Pause through time" while it plays. Icons are aria-hidden.
Keyboard
Tab to reach, Enter or Space to press. Focus shows the ring only on :focus-visible.
Google
Hidden, with its "or" divider, when Google sign-in is off. Google's own mark goes in the dashed box.

Text fields

For anything typed or picked. Sign-in fields are 48 tall; everything in the app is 44.

Measurements

  • Height 48 sign-in · 44 in the app, including select, search and token field size.field-l · size.field
  • Border 1px field-border; hover 1px ink-3; focus and error 2px (brand, error-border). Search has no border colour.field-border · colour.ink-3 · colour.brand · colour.error-border
  • Radius 8 · eye button 6 · chips fully round radius.control · 6: no token · radius.full
  • Padding 0 12 select · 0 14 sign-in (0 56 0 14 with the eye) · token field 4 8 space.12 · space.4 · space.8 · 14: no token
  • Text 16 sign-in and phone · 16 in this platform's app fields type.body-l · type.body
  • Label 14 / 20 · 600, 8 above the field type.label · space.8
  • Chip in a field 36 tall, brand-tint, brand-hover text 14 / 500; × button 36 × 36 size.chip · colour.brand-tint · 14/500: no token
  • Helper, error 13 / 20 ink-3; error 13 / 20 in error type.small · type.caption · colour.error
  • Icons search 18 · chevron 18 · eye 20 · error 18, 12 from the right no token

Accessibility

Label
Every field has a visible <label for>. Search has no visible label, so it takes aria-label="Search people and places".
Password
The eye is a button type="button": aria-label="Show password", then "Hide password" while shown. The field switches between type="password" and type="text". After a failed sign-in, clear it.
Select
A native <select>, so arrow keys and Alt + Down work. The chevron is aria-hidden.
Search
type="search". The "/" hint is aria-hidden; the field has aria-keyshortcuts="/".
Token field
The input is labelled "Surname". Each chip's × is a button named "Remove Rossouw". Enter adds a surname.
Errors
aria-invalid="true", and aria-describedby points at the error text.

Chips

Event type filters, each with its glyph, and the removable chip a token field holds.

Measurements

  • Height 44, fully round, on a phone size.touch · radius.full
  • Padding 0 12 · glyph 8 from the label space.12 · space.8
  • Label 13.5 / 20; 600 when on, 400 when off type.chip (600) · 13.5/400: no token
  • Colours Off: white, 1px line-strong, ink-3. On: brand-tint, 1px brand, brand-hover. Glyph in pin colour.line-strong · colour.brand-tint · colour.brand · colour.pin
  • Removable 36 tall, padding 0 0 0 12; × 36 × 36; 14 / 500 brand-hover on brand-tint size.chip · 14/500: no token
  • Gap 8 between chips space.8

Accessibility

Role
Event chips are toggle buttons: button aria-pressed. The set sits in a fieldset with the legend "Event type".
Name
The event name. The glyph is aria-hidden; the shape repeats what the word says.
Removable
The × is its own button, aria-label="Remove Rossouw". When it goes, focus moves to the surname input.
Keyboard
Tab between chips, Space or Enter toggles.

Tabs

Switch between the Layers and Filters panels. The badge counts the filters that are on.

Measurements

  • Height 44 on a phone, 40 in the desktop panel size.control · size.control-s
  • Width Equal: each tab takes half the row (flex: 1) —
  • Bar Padding 6, gap 4, 1px line under it (desktop) · phone: 8 under the row, gap 8 to Close 6: no token · space.4 · space.8 · colour.line
  • Label 14 / 20 · 600; selected brand-hover on brand-tint, others ink-3 type.label · colour.brand-tint · colour.brand-hover
  • Badge 20 tall, min-width 20, fully round, brand, white 12 / 600; 8 after the label radius.full · colour.brand · 12/600: no token
  • Radius 8 radius.control
  • Close 44 × 44, fully round, ink-3, 20px icon size.touch · radius.full · colour.ink-3

Accessibility

Role
A tablist holding two tab elements with aria-selected, each controlling a tabpanel. The mockups use aria-pressed buttons; see the reply.
Name
The label plus the count: "Filters, 1 active". The badge alone would read as "Filters 1".
Keyboard
Tab moves into the tablist; Left and Right move between tabs and select them.
Close
aria-label="Close". It closes the sheet and returns focus to the Layers button.

Checkbox field

A checkbox with its name, and on layer rows a line of live detail. Sign-in uses the plain label form.

Measurements

  • Row min-height 48; the whole row is the label, so all of it is the hit area size.field-l
  • Checkbox 20 × 20, radius 4, 1.5px field-border off, brand fill on size.checkbox · radius.small · colour.field-border · colour.brand
  • Gap 12 between box and text · 10 on sign-in space.12 · 10: no token
  • Name 14 / 20 · 600 ink type.label
  • Description 13 / 20 ink-3; live facts, such as pins true on the date type.small · colour.ink-3
  • Label only 14 / 400 ink-2 14/400: no token · colour.ink-2

Accessibility

Role
A native input type="checkbox" inside its <label>, so clicking the text toggles it.
Name
The name. Tie the description with aria-describedby so it is read after the name.
Live
The description changes with the date ("8 of 214 true on this date"); it is not a live region, so it is read when focused, not on every change.
Keyboard
Tab to reach, Space toggles. Focus ring on the box.

Alerts

For a problem with one part of the screen. Use the untitled form when the one line says it all.

Measurements

  • Padding 12 14 · radius 8 space.12 · 14: no token · radius.control
  • Border Untitled: error-border-soft · titled: error-border colour.error-border-soft · colour.error-border
  • Fill, text error-bg, error text colour.error-bg · colour.error
  • Icon Untitled: 18 outline in currentColor, 10 from the text · titled: 20 filled circle, 12 from the text 10: no token · space.12
  • Text Untitled: 14 / 1.45 · titled: 14 / 600 title, 13.5 / 1.4 line 14/400, 13.5/400: no token · type.label

Accessibility

Role
role="alert": a failed sign-in is an error. It is announced without moving focus.
Fields
Both fields get aria-invalid="true". The password is cleared, with the helper "Password cleared after a failed attempt."
Icon
aria-hidden; the words carry the meaning.

Dividers

Separate groups that sit close together. Use space first; reach for a line when space alone doesn't read.

Measurements

  • Line 1px line colour.line
  • "or" 13 / 400 ink-3, 12 from each line 13/400 (type.small size) · space.12 · colour.ink-3
  • Footnote 20 between rule and text; 13 / 1.55 ink-3 space.20 · type.small

Accessibility

Hairline
Decoration: a span or an hr with aria-hidden, so it isn't read.
"or"
The word is read; the two lines are aria-hidden.

Key hints

Show a keyboard shortcut next to what it does. Desktop only: phones have no keyboard to hint at.

Measurements

  • Text JetBrains Mono 12 / 16 in the search field · 11 in the dock hints type.mono · 11 mono: no token
  • Padding 2 6 search · 1 5 dock no token
  • Border 1px line-strong, radius 4 colour.line-strong · radius.small
  • Colour ink-3 colour.ink-3

Accessibility

Element
A <kbd>.
Search
The "/" hint is aria-hidden; the field carries aria-keyshortcuts="/" instead.
Dock
Read as the sentence it sits in. The slider's own label already says "Arrow keys step one year, Shift and arrow ten years".
