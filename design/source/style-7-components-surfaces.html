Surfaces and overlays

The cards, dialogs, sheets, menu, popup and callout that sit above the map, from the panel up to the modal dialog.

Surface

Everything that sits above the map is a white surface at one of four levels. The higher it sits, the more it interrupts.

Measurements

Fill white colour.surface
Radius 12 · phone sheets 18 on top radius.panel · radius.sheet
Raised panels, dock, search bar, notice cards, map controls shadow.raised
Floating popups and menus shadow.floating
Modal dialogs, with the scrim behind shadow.modal · colour.scrim
Sheet phone sheets shadow.sheet
Off the scale Desktop avatar 0 4 14 / 0.16 · phone search pill and layers button 0 6 20 / 0.14 (map-phone) · banner 0 6 20 / 0.2 · date callout 0 6 20 / 0.12 no token

Accessibility

Contrast
Shadows separate surfaces but carry no meaning. Text on white passes 4.5:1; borders are not needed for contrast.
Scrim
The modal level always comes with the scrim, which blocks the map for pointer and screen reader alike (aria-modal="true").

Notice card

For empty and loading states on the map. Says what's going on in one line and offers at most two ways out.

Measurements

Width 360 on desktop (380 for the large form) · full width less 16 gutters on a phone 360, 380: no token · size.gutter-phone
Padding 16 18 · loading 18 20 · large 20 22 space.16 · space.20 · 18, 22: no token
Gap 12 inside (10 in the desktop loading card); icon 20, 12 from the text; buttons indent 32 space.12 · 10: no token
Title 15 / 22 · 600 · large form Bricolage 20 / 700 type.title · 20 Bricolage: no token
Line 13.5 / 1.45 ink-2 · loading 13 ink-3 14/400, 13.5/400: no token · type.small
Buttons 40 tall: primary then secondary, 8 apart size.control-s · space.8
Surface white, radius 12, raised shadow colour.surface · radius.panel · shadow.raised

Accessibility

Role
role="status", so the change is announced politely. The loading card adds aria-live="polite".
Icon
aria-hidden.
Buttons
Real buttons in reading order after the text. Jump to moves the map date; Clear filters clears every filter.
Focus
The card never takes focus; it explains, and the buttons are there to Tab to.

Progress bar

Shows how much of the first load is done. Only ever inside the loading notice card.

Measurements

Track 6 tall, fully round (3), line 6, 3: no token · colour.line
Fill brand, same height and radius; width is the share loaded colour.brand
Width Fills the card —
Kind Determinate. There is no indeterminate form on any screen —

Accessibility

Role
role="progressbar" with aria-valuenow, aria-valuemin="0", aria-valuemax="100", labelled by the card title "Loading the map". The mockup has none of these yet.
Motion
Width changes without easing under prefers-reduced-motion.

Accessibility

Role
role="dialog" with aria-modal="true", labelled by its title (aria-labelledby). The mockups use aria-label.
Focus
Opening moves focus into the dialog (the Close button); Tab stays inside; closing returns focus to the link or menu item that opened it.
Keyboard
Esc closes. On a phone, dragging the handle down closes too, but Close is always there.
Table
A real table on desktop (role="table", column headers); a list on a phone, where each item reads layer, source, licence, checked.

Phone sheet header

The top of every phone bottom sheet: a handle, then one of three header rows.

Padding 8 16 at the top; 8 (tabs) or 12 (title) from handle to header space.8 · space.16 · space.12

Accessibility

Heading
The title is a real h2 and labels the sheet's dialog.
Close
aria-label="Close"; Esc does the same.
Handle
Decoration on an open sheet (aria-hidden). On the collapsed date sheet it is a button, "Expand the sheet", which isn't covered here.

A short list of actions behind a trigger. Today only the account menu, opened from the avatar.

Accessibility

Trigger
The avatar is a button named "Account menu", with aria-haspopup="menu" and aria-expanded.
Role
role="menu" with menuitem children. The header and footer text sit outside the menuitems (role="none" or a labelled group) so arrow keys skip them.
Keyboard
Opening moves focus to the first item. Up and Down move, Enter activates, Esc closes and returns focus to the avatar. Tab leaves and closes.
Name
The menu is labelled "Account". Icons are aria-hidden.

Popup

Answers "what was this spot part of on the map date?" where you clicked: the Jurisdiction chain and the pins there.

Measurements

Header Overline "On this spot in {year}" · place name H3 Bricolage 22 · 700 (−0.01em on desktop) · coordinates mono 12 ink-3 type.overline · type.h3 · type.mono

Pins here Inset: surface-2, radius 8, padding 10 12, gap 6; row min 32. Glyph 14 pin, title 14 / 600, people 13 ink-3, date mono 12 ink-2 colour.surface-2 · type.label · type.small · type.mono · 10, 6, 32: no token
Copy chain Desktop only: 36 secondary with the copy icon (board 06) —

Accessibility

Role
Desktop: a non-modal role="dialog" named "Jurisdiction at this point". Phone: a region of the bottom sheet named by its overline.
Focus
Opening a popup with the keyboard moves focus to it; Esc or Close returns focus to the map.
Chain
An ordered list (<ol>), smallest unit first. Each row reads level then name.
Pins
Each pin is a link to its record. The glyph is aria-hidden; the event name says what it is.
Copy chain
Copies the chain as text and confirms with the "Jurisdiction chain copied." toast (board 05).

Callout

A message that belongs to one control and has to point at it: today, the error on the map date field in the dock.

Measurements

Box 340 wide · padding 10 12 · radius 8 340, 10: no token · space.12 · radius.control
Colours error-bg, 1px error-border, error text colour.error-bg · colour.error-border · colour.error
Text 13.5 / 1.4; first sentence 600 type.label (600) · 13.5/400: no token
Pointer 12 square turned 45°, error-bg with the box's border on its two outer sides, 7 below the box 12, 7: no token
Shadow 0 6 20 / 0.12 (the second half of raised) no token
Place Opens above the field it belongs to, so it isn't cut off at the bottom of the screen —

Accessibility

Role
role="alert", with an id the field points at through aria-describedby.
Keyboard
Esc restores the last good date and closes the callout.
Pointer
Decoration (a styled span), never read.
