Map furniture

The pieces that live on the map itself: the wordmark, search bar, map controls, event glyphs, the legend and the date dock.

States not drawn here follow board 04: hover tints, a 2px focus ring, disabled colours. A tap target under 44 keeps a 44 × 44 hit area.

Wordmark

The icon, then "KinScape" in Bricolage Grotesque 700. Drop the name only where there is no room for it.

Measurements

Name "KinScape", capital S, Bricolage Grotesque 700: H2 on desktop sign-in, H3 everywhere else type.h2 · type.h3
Gap 12 between icon and name space.12
Colour ink colour.ink

Accessibility

Alt
Beside the name the icon is decoration: alt="". Alone (the phone pill) it is alt="KinScape".
Link
On the map the wordmark is not a link. If it becomes one, it goes to the map at the current date and is named "KinScape, map".

Accessibility

Role
Wrap it in role="search". The input is type="search", named "Search people and places".
Keyboard
"/" focuses the field from anywhere on the map (desktop). Esc clears, then leaves.
Focus
The mockups set outline: none and draw no focus, so it isn't drawn here; it follows board 04.
Results
Search results are not designed yet (EXP-04).

Accessibility

Names
"Zoom in", "Zoom out", "Fit South Africa", "Layers and filters". Icons are aria-hidden.
Disabled
At the zoom limit use aria-disabled="true" so the button stays in the Tab order and says why.
Focus
Each button rounds its own corners, so the card doesn't clip and the outside focus ring shows in full.
Keyboard
The map itself also takes + and −.

Event glyphs

One shape per event type, used wherever an event appears: chips, the legend, pin rows and the map.

Measurements

Colour pin, in every size colour.pin
Sizes 12 · 14 · 16; in running text they take the text size (13 legend, 13.5 chips, 14 pin rows) no token
Font Unicode characters set in Public Sans; the browser falls back for ∞ † ⚰ ▪ where Public Sans lacks them font.body
On the map SDF icons in pin with a 2px white halo (map style board) map.pin.colour · map.pin.halo-width

Accessibility

Hidden
Always aria-hidden="true"; the event name is always written next to it.
Shapes
Each event has its own character (* ∞ % † ~ ⚰ ▪ •), so meaning never rests on colour alone and holds up in greyscale (NFR-06).

Accessibility

Group
The dock and the sheet are a region named "Map date".
Field
The date field is the only date readout: the slider's thumb is named for the date it sits on. Invalid dates: board 05.
Slider
Arrow keys step one unit at the chosen precision, Shift and an arrow ten. The thumb is a role="slider" with aria-valuetext set to the date.
Segmented
Each item is a button with aria-pressed; the group is labelled "Date precision" or "Playback speed in years per second".
Play
"Play through time", then "Pause through time" while it plays.
Grabber
A button named "Expand the sheet", with a 44 × 44 hit area.
