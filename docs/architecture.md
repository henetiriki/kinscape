# Architecture

Built: Next.js App Router, React, TypeScript, MapLibre.

## Where does X go

| Change                          | Put it in                                                                                     |
| ------------------------------- | --------------------------------------------------------------------------------------------- |
| A screen or route               | `app/<route>/page.tsx` ([page rule](../design/DESIGN.md#components))                          |
| Shared UI                       | `app/components/<role>/`                                                                      |
| UI only the map or sign-in uses | `features/map/components/`, `app/components/auth/`                                            |
| UI the kit and features share   | `lib/ui/`                                                                                     |
| A feature's UI and engine       | `features/<name>/`                                                                            |
| A map layer                     | `features/<name>/layers/<layer>.ts`, exported by `index.ts`; routes pass layers to `MapShell` |
| Pure logic, no I/O              | `lib/domain/`, tests in `__tests__/`                                                          |
| Reading data files              | `server/boundaries/load.mts` and `app-data.ts`                                                |
| A server variable or table      | `server/env.mts`; a new `server/db/migrations/NNNN.sql` (never edit)                          |
| Tree data                       | `server/trees/`, behind `openTree`: an entity's port, group and mapper                        |
| Design checks and token tooling | `lib/design/` (dev-only); the runtime `resolveTokens` is in `design/tokens.mts`               |
| A colour, size or font value    | `design/tokens.json` + notes, then `npm run tokens`                                           |
| Boundary and name data          | `data/`; basemap files in `public/map/` (`npm run map:prepare`)                               |
| A tool, check or CI helper      | `scripts/`, its test beside it                                                                |
| A browser test                  | `e2e/`                                                                                        |
| A type shared by two modules    | `types.ts` beside them (`import type`, also in `.mts`)                                        |

Import repo paths by alias: `#ks/` in `.mts` and `.mjs` files, `@ks/` elsewhere. ESLint rejects the other alias, relative paths and `.ts`/`.tsx` imports (`.mts`: values only).

## Patterns

| Pattern                                                                                                                                                                                                                                                    | Where                                                                                                    | Enforced by                                                                                                  |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Tokens are the one source.** CSS variables, MapLibre paint values and map padding read `design/tokens.json`.                                                                                                                                             | `design/tokens.mts`, `lib/design/css.mts`, `features/map/style.ts`, `layers/`, `Stage.tsx` `freeArea`    | `lib/design/__tests__/design.test.ts` fails if `app/tokens.css` is stale                                     |
| **Components by role.** One folder per role: its components, their `.module.css` and `__tests__/`.                                                                                                                                                         | `app/components/`                                                                                        | ESLint `no-restricted-imports`; [DESIGN.md](../design/DESIGN.md#components)                                  |
| **Variants are data attributes.** `data-size`, `data-state`, `data-form` select the look in the component's `*.module.css` (camelCase classes); a shared rule has its own module, taken with `composes`.                                                   | `Button.tsx`, `foundation/focus.module.css`                                                              | Review                                                                                                       |
| **Slots.** A frame places named boxes over the map, desktop and phone forms.                                                                                                                                                                               | `features/map/components/Stage.tsx`                                                                      | Review                                                                                                       |
| **State in the shell, controlled children.** `MapShell` owns the Map date and layer toggles; children are controlled; `usePhone` picks the form, the server renders desktop.                                                                               | `features/map/components/MapShell.tsx`, `foundation/usePhone.ts`                                         | Review                                                                                                       |
| **Functional core, imperative shell.** Pure functions in `lib/domain`; only `MapView` creates or drives the map; `style.ts`, `layers/` and `filter.ts` build MapLibre styles and expressions from its types.                                               | `lib/domain/`, `features/map/components/MapView.tsx`                                                     | Tests (100% coverage)                                                                                        |
| **Temporal validity.** A `Day` counts days since 1652-01-01; a `Validity` is half-open `[validFrom, validTo)`, null = current; `isCurrentOn` applies it, `dateFilter` as a MapLibre expression.                                                            | `lib/domain/validity/`, `lib/domain/boundaries/model.mts`, `lib/domain/dates/`, `features/map/filter.ts` | Unit tests; `filter.test.ts` checks the two agree                                                            |
| **Shared controls run on React 18 and 19.**                                                                                                                                                                                                                | `app/components/{actions,feedback,forms}/`, `DateField.tsx`                                              | `lib/design/__tests__/react-18.test.tsx`                                                                     |
| **Load once, filter by expression.** All Boundary versions load once; a Map date change only sets filters (NFR-01).                                                                                                                                        | `features/map/filter.ts`, `style.ts`, `components/MapView.tsx`                                           | `@perf` e2e tests                                                                                            |
| **Map layers.** A `Layer` holds id, label, description, sources, drawing layers and `filters(day)`; `visible[id]` defaults on; one panel row each; `MapView` names none.                                                                                   | `features/map/types.ts`, `layers/`                                                                       | `features/map/__tests__/layers.test.ts` (`'use client'` each)                                                |
| **Reference data is files, validated.** `validate:boundaries` stops bad data; `/data/polities` is per request, 401 unsigned.                                                                                                                               | `data/`, `server/boundaries/app-data.ts`, `app/data/polities/route.ts`                                   | `npm run validate:boundaries`                                                                                |
| **Schema first.** A Zod schema parses; `types.ts` derives the type from it.                                                                                                                                                                                | `lib/domain/boundaries/schemas.mts`, `types.ts`, `server/boundaries/load.mts`                            | `npm run typecheck`; `server/boundaries/__tests__/load.test.ts`                                              |
| **Living style guide.** `/design-kit` shows components, `/screens` screens; 404 outside Preview and development (`proxy.ts`, `requireDevPage()`).                                                                                                          | `app/design-kit/`, `app/screens/`, `e2e/design-check.spec.ts`                                            | `npm run design:check`; `/match-design`                                                                      |
| **Tree data.** `openTree` is the only entry: it resolves the session to a Viewer, opens the Tree and builds the entity groups; reads map rows with a `ToView` (NFR-10). `treeAction` reads the cookie.                                                     | `server/trees/`, `server/action.mts`                                                                     | `server/trees/__tests__/contract.ts`; `scripts/__tests__/scoping.test.ts` and ESLint `no-restricted-imports` |
| **Tree-scoped tables.** A table with `tree_id` has primary key `(tree_id, id)`, `version`, `created_at`, `updated_at`, composite foreign keys to other Tree-scoped tables, and a client-sent UUIDv7 `id`. Copy `server/db/TEMPLATE.sql`.                   | `server/db/TEMPLATE.sql`, `server/db/migrations/`                                                        | `server/db/__tests__/tree-scoped.test.ts`                                                                    |
| **Sign-in gate.** `proxy.ts` checks a cookie exists (skipping static file types); `requireSession()` per page and `currentSession()` per route handler is the full check. Visibility and auth checks go in the page or `openTree`, never only in a layout. | `proxy.ts`, `server/auth/current.mts`, `sessions.mts`                                                    | `scripts/__tests__/gate.test.ts`, `__tests__/proxy.test.ts`, `e2e/gate.spec.mts`                             |
| **Client/server boundary.** `server-only` opens each server entry point; a `'use client'` file imports no value from `server/`.                                                                                                                            | `server/{action,adapters}.mts`, `auth/current.mts`, `boundaries/app-data.ts`                             | `scripts/__tests__/boundary.test.ts`; ESLint `safety/client-imports`                                         |
| **Providers behind ports.** Supabase only in allowlisted files; Kysely over `pg`; plain Postgres, no row-level security.                                                                                                                                   | `server/adapters.mts`                                                                                    | `scripts/__tests__/providers.test.ts`                                                                        |
| **Traceability.** Tests carry `// MAP-03` tags; plans and PRs cite IDs; code uses the Key concepts terms.                                                                                                                                                  | `docs/requirements.md`, `plans/`                                                                         | Review                                                                                                       |

## Enforcement

- **Lint** (`eslint.config.mjs`): arrow functions only, exported types only in `types.ts`, no default exports outside Next.js files, sorted keys and imports, accessibility rules, alias imports by extension, stylesheets last, type imports on their own line.
- **Fitness tests** (`scripts/__tests__/`): `vercel-imports` (undeployed imports); `scoping`, `gate` and `boundary` (the three safety rows, from `scripts/safety.mts`).
- **Layers** (`scripts/layers.mts`, ESLint rule `layers/imports`, fitness test `scripts/__tests__/layers.test.ts`): a path's layer may import only the layers in its row. `lib/domain` may not import Node built-ins or `maplibre-gl`. `features/` holds only feature folders, imported from outside through `index.ts`. Tests, `app/design-kit`, `app/screens`, `scripts`, `e2e` and `lib/design` are outside the map; mapped code may not import them.
  | Layer             | Holds                                  | May import                                                                                   |
  | ----------------- | -------------------------------------- | -------------------------------------------------------------------------------------------- |
  | `design`          | `design/`                              | nothing                                                                                      |
  | `lib/domain`      | pure logic and types                   | itself                                                                                       |
  | `server/`         | file and database access               | `lib/domain`, itself                                                                         |
  | `lib/ui`          | UI the kit and features share          | `design`, itself                                                                             |
  | `app/components`  | the shared UI kit                      | `design`, `lib/ui`, itself                                                                   |
  | `features/<name>` | that feature's UI, queries and actions | `design`, `lib/domain`, `server/`, `app/components`, `lib/ui`, itself; never another feature |
  | `app/` routes     | pages, route handlers, server actions  | everything above                                                                             |
