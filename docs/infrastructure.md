# Infrastructure

## Vercel

Vercel has no settings-as-code here: the tech lead sets these by hand in the Vercel dashboard, and nothing checks for drift. Update this table in the same PR as any change.

| Setting                      | Value                                                                                                                                                                                              | Why                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Project                      | `kinscape`, Hobby plan, Git repo `henetiriki/kinscape`                                                                                                                                             | Builds previews and production; the Deploy rule below says which pushes skip                                                                                                                                                                                                                                                                                                                                                              |
| Production branch            | `main`                                                                                                                                                                                             | Production only changes through a merged PR                                                                                                                                                                                                                                                                                                                                                                                               |
| Framework, Node              | Next.js; Node 24.x (from `package.json` `engines`)                                                                                                                                                 | Matches local development                                                                                                                                                                                                                                                                                                                                                                                                                 |
| System Environment Variables | "Enable access to System Environment Variables" is on (Project Settings, Environment Variables)                                                                                                    | Vercel then sets `VERCEL` and `VERCEL_ENV` at build and runtime ([docs](https://vercel.com/docs/environment-variables/system-environment-variables)). Off, Preview hides the design kit and screens (`server/dev-pages.mts`). The `KINSCAPE_MEMORY_ADAPTERS` and `KINSCAPE_DEV_PAGES` guards below then never fire. Nothing checks the setting. After each production deploy, run `npm run check:production -- <url>` to check the result |
| Vercel Authentication        | Previews and production need a Vercel sign-in. Protection Bypass for Automation has a secret, which the tech lead keeps in their shell as `VERCEL_AUTOMATION_BYPASS_SECRET` for `check:production` | Production leaves it when M2 sign-in (NFR-03) ships to production. Previews stay behind it                                                                                                                                                                                                                                                                                                                                                |
| Ignored Build Step           | Automatic (the default) in the dashboard; `vercel.json` runs `scripts/vercel-ignore.mts`                                                                                                           | The file is the only rule                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Deploy rule                  | A push skips its deployment only when every changed file is on the invisible list in `scripts/vercel-ignore.mts`. `po-preview` always deploys. If the script can't read GitHub, it deploys         | Plan, docs, test and CI changes nobody can see don't deploy, and a docs-only merge doesn't redeploy production                                                                                                                                                                                                                                                                                                                            |
| `KINSCAPE_REPO_SLUG`         | The repo as `owner/name`; Production and Preview. Set by hand: the script has no Vercel login                                                                                                      | The script asks the GitHub API about this repo. Unset, every push deploys                                                                                                                                                                                                                                                                                                                                                                 |
| `KINSCAPE_GIT_READ_TOKEN`    | Fine-grained token for `henetiriki/kinscape` only, Contents read-only; Sensitive, Production and Preview; expires after 90 days; the owner rotates it                                              | The script reads the changed files from the GitHub API, as Vercel's clone has no remote. Once it expires, every push deploys until someone sets a new one                                                                                                                                                                                                                                                                                 |

Database variables (NFR-03, NFR-09). All are Sensitive; the values are in Vercel only, never in git. Preview points at `kinscape-preview`, Production at `kinscape-production`. Before you run `db:migrate` or `account:add` with production variables, diff the script against the version you last ran.

| Variable                            | Value                                                                                                                                        | Why                                                                                                                                                                                                                                                                                                                                                                   |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `KINSCAPE_DATABASE_URL`             | The project's transaction-pooler connection string (port 6543) ending `?sslmode=verify-full`; Production and Preview, each its own project's | The app's database connection (`server/env.mts`). The transaction pooler supports no named prepared statements, so the client turns them off. A Production value in Preview would put synthetic data beside the real Tree. The server verifies the certificate against `server/db/root-ca.crt` whatever the URL says, and refuses to start on any other TLS parameter |
| `KINSCAPE_SUPABASE_URL`             | The project's API URL; Production and Preview, each its own project's                                                                        | Sign-in                                                                                                                                                                                                                                                                                                                                                               |
| `KINSCAPE_SUPABASE_PUBLISHABLE_KEY` | The project's publishable key; Production and Preview, each its own project's                                                                | Signs Accounts in but can't manage them. The app does not use the secret key, and nothing sets it                                                                                                                                                                                                                                                                     |
| `KINSCAPE_DATABASE_DIRECT_URL`      | The project's session-pooler connection string (port 5432) ending `?sslmode=verify-full`; in no Vercel environment                           | Only for `npm run db:migrate` and `account:add`, which the tech lead runs locally from a git-ignored `.env.local`. Migrations need a session, which the transaction pooler doesn't keep. Same TLS rules as `KINSCAPE_DATABASE_URL`                                                                                                                                    |
| `KINSCAPE_MEMORY_ADAPTERS`          | `1` in local dev and e2e only; never set in Vercel                                                                                           | Test-only: uses the memory session, sessions, store and sign-in throttle. It needs no database or Supabase variable. The server refuses to start if `VERCEL` or `VERCEL_ENV` is also set (see _System Environment Variables_ above)                                                                                                                                   |
| `KINSCAPE_DEV_PAGES`                | `1` in e2e only; never set in Vercel                                                                                                         | Test-only: shows the design kit and screens in a production build (`next start`). The server refuses to start if `VERCEL` or `VERCEL_ENV` is also set                                                                                                                                                                                                                 |
| `KINSCAPE_E2E_SPLIT`                | `1` in the CI `e2e` job only; never set in Vercel                                                                                            | Test-only: `playwright.config.ts` drops the `design` project, which the CI `design` job runs. The app does not read it                                                                                                                                                                                                                                                |

## Supabase

Supabase has no settings-as-code here: the tech lead sets these by hand in the Supabase dashboard, and nothing checks for drift.

| Setting                             | Value                                                                                                                                        | Why                                                                                                                                                                                                         |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Projects                            | `kinscape-preview` (Vercel Preview) and `kinscape-production` (Vercel Production); free tier                                                 | Preview deployments never touch the real Tree                                                                                                                                                               |
| Region                              | `eu-west-1` in both projects                                                                                                                 | Cape Town if offered, else EU                                                                                                                                                                               |
| Sign-ups                            | Off in both projects                                                                                                                         | v1 has no sign-up ([requirements](requirements.md) _Users_, NFR-03)                                                                                                                                         |
| Email provider                      | On in both projects (Authentication → Sign In / Providers → Email)                                                                           | Sign-in is Supabase Auth's password grant; with it off Auth answers 422 and every sign-in shows "can't sign you in right now"                                                                               |
| Data API                            | Off ("Only connection string") in both projects; Supabase Auth stays on                                                                      | The app reaches Postgres directly and never uses `supabase-js` for data, so nothing needs it                                                                                                                |
| Automatic RLS on new tables         | On in both projects                                                                                                                          | With no policies it denies the anon and authenticated roles. The server connects as the table owner, which bypasses RLS, so RLS does not affect app queries. A second layer if someone enables the Data API |
| Disabling an Account                | Also delete its `session` rows                                                                                                               | Supabase Auth doesn't know the app's sessions; they last up to 90 days                                                                                                                                      |
| Clearing a sign-in lock             | `delete from sign_in_failure where email_key = encode(sha256(convert_to('<email>', 'UTF8')), 'hex')`, with the email trimmed and lower-cased | Five failures lock an email for 15 minutes; rows hold only the hash (NFR-03)                                                                                                                                |
| Pausing                             | An idle free project pauses; the tech lead resumes it in the dashboard                                                                       | Free tier limit                                                                                                                                                                                             |
| Enforce SSL on incoming connections | On in both projects (Settings → Database → SSL)                                                                                              | Only TLS connections reach Postgres and the poolers. The server pins `server/db/root-ca.crt` (Supabase Root 2021 CA, expires 26 April 2031); replace the file in a PR before then                           |
