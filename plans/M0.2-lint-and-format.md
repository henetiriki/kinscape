# Plan: M0.2: Lint and format

- **Spec:** #9
- **Requirement IDs:** none (M0 Foundations: CI with lint)
- **Status:** approved

## Approach

Add ESLint 9 (flat config) and Prettier, a GitHub Actions workflow that runs both on every PR, and bring the existing files into line. ESLint 9, not 10: `eslint-config-next`'s React, import and a11y plugins don't accept 10. TypeScript moves from 7.0.2 to 6.0.3, because typescript-eslint needs TypeScript's JS API, which 7 doesn't ship (tech lead's choice). The check is not required until M0.5.

Rule sources, settling the Spec's flagged concerns:

- **Function style:** core `no-restricted-syntax` bans `FunctionDeclaration` and non-method `FunctionExpression`; `prefer-arrow-callback` too. No plugin.
- **Unused imports:** `@typescript-eslint/no-unused-vars` (error).
- **Sorting:** `eslint-plugin-perfectionist` `recommended-alphabetical`.
- **Hooks and a11y:** `eslint-config-next` (`core-web-vitals`, `typescript`), plus every `jsx-a11y` recommended rule as an error.
- **Padding lines:** `@stylistic/padding-line-between-statements` with the Spec's options; the core rule is deprecated.
- **`package.json` scripts:** `eslint-plugin-package-json` `sort-collections`, parsed by `@eslint/json`.
- `eslint-config-prettier` last. `eslint --max-warnings 0`, so warnings fail too.

## Order of work

1. Commit this plan on `spec/M0.2-lint-and-format`, cut from `origin/main`.
2. Install deps, pin TypeScript 6.0.3, run `npm run build`.
3. Add configs, scripts and the workflow.
4. Run `prettier --write .` and `eslint --fix .`; fix the rest by hand. Formatting is its own commit.
5. List what remains in `.claude/` (the sandbox can't write there) for the tech lead.
6. Prove the failing cases, update `AGENTS.md`, open the PR (Closes #9).

## Risks

- **Prettier reflows Markdown tables,** `requirements.md` included. Words unchanged; separate commit keeps the diff reviewable.
- **Perfectionist vs meaningful order,** e.g. the MapLibre style object. Disable per line with a comment only where order matters.
- **TypeScript 6 vs 7:** `npm run build` proves Next still type-checks.

## Proof

| Acceptance check | Proven by |
|---|---|

| CI lint and format checks fail on errors | Throwaway draft PR with a function declaration and an unformatted file: CI red, then closed |
| Existing files pass | `npm run lint` and `npm run format:check` green locally and in this PR's CI |
