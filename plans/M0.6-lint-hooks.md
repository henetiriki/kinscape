# Plan: M0.6: Lint hooks

- **Spec:** #19
- **Requirement IDs:** none (M0 Foundations: tooling)
- **Status:** approved

## Approach

Husky 9.1.7 runs lint-staged 17.6.0 on `git commit`; a Claude Code PostToolUse hook runs a wrapper script that calls `npm run fix:file` on the edited file. Both reuse the M0.2 ESLint and Prettier configs unchanged.

- **lint-staged** (`.lintstagedrc.json`): `*.{js,jsx,mjs,cjs,ts,tsx,json}` → `eslint --fix --max-warnings 0 --no-warn-ignored`; `*` → `prettier --write --ignore-unknown`. The pre-commit hook runs `lint-staged --concurrent false` so the two never write one file at once. `--no-warn-ignored` stops JSON files with no ESLint config (e.g. `tsconfig.json`) tripping `--max-warnings 0`.
- **`fix:file`:** `sh -c 'prettier --write --ignore-unknown "$0" && eslint --fix --max-warnings 0 --no-warn-ignored "$0"'`; npm appends the path, which becomes `$0`. Ignored files exit 0 silently in both tools.
- **Wrapper** `scripts/fix-edited-file.mjs`: reads the hook JSON from stdin, takes `tool_input.file_path`, exits 0 for paths outside `CLAUDE_PROJECT_DIR` or files that no longer exist, otherwise runs `npm run --silent fix:file -- <path>`. On failure it writes the output to stderr and exits 2.
- **Install:** `"prepare": "husky"`. Husky 9 prints a notice and exits 0 when `.git` is missing (Vercel), and CI has devDependencies, so neither fails.
- **Unstaged changes:** lint-staged's default stash keeps unstaged hunks of a partially staged file; proven below.

Hook entry for the tech lead to add to `.claude/settings.json`:

```json
"hooks": {
  "PostToolUse": [
    {
      "matcher": "Edit|Write",
      "hooks": [{ "type": "command", "command": "node \"$CLAUDE_PROJECT_DIR\"/scripts/fix-edited-file.mjs" }]
    }
  ]
}
```

## Risks

- **ESLint globals in `scripts/*.mjs`** (`process`) may be undefined under the Next config. If so, scope Node globals to `scripts/**` in `eslint.config.mjs` and log a deviation.
- **`sh -c` in `fix:file`** isn't portable to Windows shells; the team is on macOS and Linux.
- **Hook not reloaded mid-session:** if the live check doesn't fire, restart the session and repeat.
