# Plan: M1.1: Boundary model and validator

- **Spec:** #65 (Intent #56)
- **Requirement IDs:** BND-01, BND-02, BND-06, BND-07
- **Status:** approved

## Approach

`lib/boundaries/model.mts` holds the types (Polity, PolityName, Source, Boundary version), `toDay`/`fromDay` (UTC days since 1652-01-01) and pure lookups: `nameOn(data, polity, day)` and `boundaryOn(data, polity, day)`. Ranges are half-open: valid from `validFrom` up to, not including, `validTo`; `null` means still current. `lib/boundaries/load.mts` reads `data/polities.json`, `data/sources.json` and `data/boundaries/**/*.geojson` once, returning the data plus any shape errors. The validator calls the loader, then applies the Spec's rules. Geometry checks use Turf: `@turf/kinks` for self-intersection, `@turf/intersect` and `@turf/area` for overlaps.

**Decisions for the tech lead:**

- **Tolerance:** an overlap counts only above 1 km² per Polity pair: well above coordinate rounding, small enough to catch a real misdrawn border. A named constant, revisited in M1.2 with real data.
- **Contested:** an overlap passes only when both features are flagged.
- **Contiguity:** a Polity's versions must meet end to start, so overlapping versions of one Polity fail too.
- **Values:** `level` is `polity` or `district`; `confidence` is `high` or `low`.

## Alternatives considered

- **`polygon-clipping`:** one package, but no self-intersection check, and Turf 7 has moved off it.
- **`@turf/turf`:** one package, but pulls in all of Turf.

## Order of work

1. Model and day conversion, with tests.
2. Loader, with tests.
3. Validator rules one at a time, test first: geometry, unknown Polity or source, date order, version gaps, name gaps and overlaps, same-level overlaps.
4. CI job, then lint, format, tests, validator and words; mark the PR ready (Closes #65).

## Risks

- **Geometry rules:** kinks finds crossing edges, not holes outside their shell. Enough for M1; noted for M4.
- **Homelands:** they sat inside provinces at the `polity` level, so M4 will need a rule for them. Not hit by the M1 epochs.
- **Pairwise overlap cost:** a bounding-box check first; fine at M1 sizes.
