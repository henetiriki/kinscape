# Plan: M1.5.1: Map date dock

- **Spec:** #88 (Intent #56)
- **Requirement IDs:** MAP-03, MAP-04, NFR-01
- **Status:** approved

## Approach

`MapShell` owns the Map date (a day number, starting today); `DateDock` owns the precision. All date maths lives in `lib/map/map-date.ts`: bounds, steps, slider snap and label. The slider is a native range input valued in steps at the precision, so snapping is exact and the keyboard works. Each change reuses `polityFilters`: four `setFilter` calls, no fetch. Credits move under the dock; the first view gets `padding` for the panel and dock (DESIGN.md › Layout).
