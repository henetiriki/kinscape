# Plan: M2.11.5.2: Leave warning on the edit page

- **Spec:** #858
- **Requirement IDs:** [PPL-02](../docs/requirements.md#ppl-02), [NFR-05](../docs/requirements.md#nfr-05)
- **Status:** approved

## Approach

`PersonForm` gets a `changed` flag. Each field change goes through `set`, so `set` sets the flag (Spec D1: B). With the flag set, a click on "Relationships" opens a `Dialog` and does not navigate (D2). "Keep editing" and the Close button close the dialog. "Leave without saving" is a `Button` with the `href` of the link. Cancel and the back link do not change. A local session swaps the boards and removes the copy.

The export test needs each `links` file in `export.json` on the canvas. So the swap deletes the `links` entry of `Person-edit-relationships.dc.html`. The back link of `Person-relationships.dc.html` then points at `Person-edit.dc.html`, which `links` already maps to `person-edit`. No snapshot changes from this edit.

## Decisions

**D2 · How the link stops for the warning** · Decides: Tech lead

`TextLink` types its `onClick` as `() => void`, so a caller cannot cancel the click.

- **A.** A `<span>` with `display: contents` holds the link. Its `onClickCapture` calls `preventDefault()` and opens the dialog. `next/link` skips a prevented click. No kit change.
- **B.** `TextLink` passes the click event to `onClick`. `TextLink` is in `CONTROLS`, so this is a design system input change. The Spec's **Design system** line ("No design system input changes") blocks it.
- **C.** After an edit, the link becomes a `TextLink` button with no `href`. Its role changes from link to button.
- **Other:** your own.

## Risks

- **A false warning.** If a field calls its change handler with no user edit, the warning shows. A `PersonForm` test opens the form, chooses the link and expects no dialog.
- **Modified clicks.** After an edit, a Ctrl or Cmd click also opens the dialog and no new tab opens. No input reaches a loss of data, so the plan adds no code. A fix checks the modifier keys, about 3 lines.
- **`design:check` fails** on `person-edit-leave`, and the design tests fail, between steps 2 and 3.
- **`DESIGN.md` is a design system input.** The edit touches only the Screens table, which is not in `README_SECTIONS`. So steps 3 to 5 of the design system do not run.
