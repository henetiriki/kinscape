# Plan: M2.14.3.2: Error props of SelectField and TextAreaField

- **Spec:** #1125
- **Requirement IDs:** [PIN-02](../docs/requirements.md#pin-02)
- **Status:** approved

## Approach

Both fields take `error?: ReactNode`, as `TextField` does. With an `error`, the box gets `data-mark='error'`, so the 2 px `--error-border` rule of `TextField.module.css` applies (Spec D1 A). The box then holds the 18 px error icon. The message replaces the helper and has the id `${id}-message`. It is `Text` `variant='small'` `tone='error'` with `role='alert'`. The control gets `aria-invalid` and `aria-describedby`.

`SelectField` puts the icon after the chevron, 8 px from it, as `draft-pin-field-errors` draws. The box stays `--size-field` (44 px). `TextAreaField` puts the icon at the top right of the box with `position: absolute`. The area keeps its rows. A 37 px gutter on the right of the box holds the icon, so the text and the scrollbar stay clear of it (D2).

Each component gets one error card state. Then the design system steps run, step 7 swaps the real fields into `pin-form-errors`, and the draft board is deleted.

**D2 · The text of a text area in error** · Decides: Tech lead

The board draws the text 8 px inside the 2 px border, with padding on the box. `TextAreaField` puts the padding on the textarea, so the resize handle sits at the padded corner. Its focus look uses 9 px 11 px, so the text stays still. No related issue holds a value for this.

- **A.** The error look uses the focus padding, 9 px 11 px, plus 37 px on the right (11 px, the 18 px icon and an 8 px gap). The icon sits 8 px from the top and 11 px from the right, inside the border. Cost: the text sits 1 px lower than on the board.
- **B.** The error look uses 8 px 11 px, as the board draws. Cost: the text moves up 1 px when the error shows.
- **Other:** your own.

## Risks

- **CSS order:** `.field > .box` in `TextAreaField.module.css` and `.box[data-mark]` in `TextField.module.css` have the same specificity. A `.field > .box[data-mark]` rule sets the padding, as the focus rule does. The gallery check of the icon place and the text padding proves it.
- **Snapshot drift:** the new bundle CSS can change class hashes in other snapshots. If a JPG other than `pin-form-errors` changes, stop and ask.
- **Card size:** the error states can need a taller card. Raise `height` in `states.mts` until the gallery shows no clip.
- **Budget:** if `npm run words` fails on `design/DESIGN.md`, shorten the bullet before you raise the budget.
