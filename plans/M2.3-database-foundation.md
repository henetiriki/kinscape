# Plan: M2.3: Database foundation

- **Spec:** #528
- **Requirement IDs:** [NFR-09](../docs/requirements.md#nfr-09)
- **Status:** approved

## Approach

A spike first runs the migration and a Kysely query on PGlite. `server/env.mts` (the Spec's `env.ts`; `.mts` so Node loads it for `db:migrate`) parses server variables with Zod, throwing a message built from names only; `instrumentation.ts` calls it at server start. `server/db/migrate.mts` reads `server/db/migrations/*.sql` in name order, stops naming any applied file whose SHA-256 differs from its `schema_migration` row, then runs each pending file and its row in one transaction. `db:migrate` uses `KINSCAPE_DATABASE_DIRECT_URL` from `.env.local` (M2.2 D3); the app, `KINSCAPE_DATABASE_URL`. Tables are singular snake_case, camelCase in code through Kysely's `CamelCasePlugin`; deleting a Tree or Account deletes its `tree_account` rows. M2.4's contract suite reuses the PGlite helper.

## Decisions

**D1 · Postgres driver** · Decides: Tech lead

- **A.** `pg` with Kysely's built-in `PostgresDialect`. It sends no named prepared statements, which the transaction pooler needs.
- **B.** `postgres` (postgres.js) with `prepare: false`, plus a community dialect package.
- **Other:** your own.

**Answer: A** (@henetiriki)

**D2 · PGlite's Kysely dialect** · Decides: Tech lead

- **A.** Our own driver of about 40 lines in the test helper, over `@electric-sql/pglite`.
- **B.** A community dialect package, its licence checked in step 2.
- **Other:** your own.

**Answer: A** (@henetiriki)

**D3 · Id type** · Decides: Tech lead

- **A.** `uuid`, defaulting to `gen_random_uuid()`. Ids reveal nothing about other Trees and suit a public Tree URL later.
- **B.** `bigint` identity: smaller and ordered, but guessable.
- **Other:** your own.

**Answer: A** (@henetiriki)

**D4 · The database URL in e2e before M2.7** · Decides: Tech lead

`npm run e2e` starts the server, which now fails without `KINSCAPE_DATABASE_URL`, and CI sets none.

- **A.** `playwright.config.ts` passes a placeholder, `postgres://e2e@localhost:5432/kinscape`, which M2.7's container then serves.
- **B.** You set it in `ci.yml`, a hand-back.
- **Other:** your own.

**Answer: A** (@henetiriki)

## Risks

- **Multi-statement files.** The D2 driver runs parameterless SQL with PGlite's `exec`, as `pg` sends a simple query. M2.7 checks the `pg` path.
- **Leaked values.** Zod issues carry the input; a test asserts a secret-looking value is absent from the message.
- **Local `npm run dev`** now needs `KINSCAPE_DATABASE_URL` in `.env.local`; the PR says so.
