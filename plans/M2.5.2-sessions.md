# Plan: M2.5.2: Sessions

- **Spec:** #555
- **Requirement IDs:** [NFR-03](../docs/requirements.md#nfr-03)
- **Status:** approved

## Approach

Migration `0002` adds `session` (`token_hash` key, `account_id` referencing `account` on delete cascade, `email`, `expires_at`, `created_at`). A `SessionStore` port (add, find, renew, remove, remove expired) has memory and database adapters; it sits beside M2.5.1's `SessionPort`, which checks passwords. `server/auth/sessions.mts` holds the rules over any `SessionStore` with an injected clock. `startSession` makes 32 random bytes, stores only their SHA-256 and returns the base64url token. `useSession` refuses a malformed token without a lookup, then sets the expiry to the earlier of now + 30 days and creation + 90 days. `endSession` deletes the row. `sessionCookie(token)` gives the name `__Host-kinscape-session` and the options. `appAdapters()` gains `sessions`, memory under `KINSCAPE_MEMORY_ADAPTERS`.

## Decisions

**D1 · How long the cookie lives** · Decides: Tech lead

- **A.** `Max-Age` of 90 days, set once at sign-in. The server enforces the 30 days, so the cookie never needs reissuing.
- **B.** `Expires` equal to the row's expiry, reissued at each renewal. The gate (M2.5.3) then sets a cookie on every request.
- **Other:** your own.

**Answer: A** (@henetiriki)

**D2 · Clearing expired rows** · Decides: Tech lead

Rows hold an email, and a session nobody presents again is never ended.

- **A.** `useSession` deletes a refused row it finds, and each `startSession` deletes every expired row.
- **B.** Only the refused row; others stay.
- **Other:** your own.

**Answer: A** (@henetiriki)

## Risks

- **Leaks.** The raw token is never stored, logged or put in an error. A test reads the PGlite row and finds no token.
- **A write per use.** Renewal updates the row on each use, as the Spec says. At family scale this is cheap; it is one keyed `update`.
- **Memory sessions across bundles (M2.5.3).** If `proxy.ts` and route handlers load separate module copies, each gets its own memory store. M2.5.3 checks this; the fix is to keep the store on `globalThis`.
- **`__Host-` needs `Secure`.** Browsers accept that on `http://localhost`, so e2e (M2.5.3) can sign in without HTTPS.
- **Size.** About 450 changed lines; past 600, I stop (rule 7).
