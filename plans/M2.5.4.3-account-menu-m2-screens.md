## Order of work

1. Record D1 to D3, then commit `plan(M2.5.4.3): approved by @<tech-lead>`.
2. Ask the tech lead in the PR to do these steps:
   - Draw the boards on the canvas.
   - Run the refresh steps on this branch.
   - Add the two `export.json` entries.
3. Read each changed board and check it against the Spec's Behaviour. List any mismatch in the PR for the tech lead.
4. Edit `DESIGN.md` and the three tests. Push, then run `gh workflow run design-agent-shots.yml --ref <branch>`. If GitHub denies it, ask the tech lead.
5. Pull the shots commit. Run all checks and `design:export` ("No snapshot changed"). Paste the output.

## Risks

- **Red until the shots commit:** the export test and `e2e` fail between steps 2 and 5. Do not mark the PR ready before then.
- **Board drift:** a canvas edit can move other parts of the map board. After the shots commit, compare each JPG with `main`'s. Stop on any change outside the menu.
