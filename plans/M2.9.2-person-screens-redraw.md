## Order of work

1. Commit the approval. Record D1 and D2.
2. The tech lead runs the Spec's prompt in the design agent, linked to this branch. Then the tech lead runs the refresh steps and commits `design/canvas/` alone.
3. Check the boards against the Spec. List each mismatch in the PR.
4. Add the `export.json` entries. `person-conflict` is `Person-new.dc.html`, variant `conflict`. `person-not-found` is the board that the design agent names. Both are 1440 × 900.
5. Add the `DESIGN.md` rows, the D2 change, the counts and `NOT_BUILT`. Run D1's steps.
6. Push. Run `gh workflow run design-agent-shots.yml --ref spec/M2.9.2-person-screens-redraw`. If GitHub denies it, ask the tech lead.
7. Pull the shots commit. Run all checks. Paste the output.

## Risks

- **Board drift:** if the shots commit changes a snapshot other than the five in the Spec, stop.
- **Colour check:** the export refuses a colour that is not a token. Ask the design agent to fix the board.
- **Old copies:** `Map-account-people.dc.html` and `Map-phone-account-people.dc.html` keep the hand-drawn menu. No snapshot reads them. This Spec does not remove them.
