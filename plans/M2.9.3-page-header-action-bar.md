## Approach

A `Button` with `href` draws an `<a>` with the same classes and `text-decoration: none`. The `NoticeCard` `.actions` rules also select `a`. `PageHeader` draws both Wordmark forms, and the phone media query shows one. `ActionBar` draws the fixed bar and an in-flow spacer of its height, which pads its page (D6). In the kit, a `contain: layout` box holds the fixed bar. Sizes come from `People-list` and `Person-new`, then from the draw.

## Deviations

- `ActionBar` has one root `div` around the spacer and the bar, so a card state has one child.
- `Card` gets an optional `contain` field. The `ActionBar` card sets it, so its fixed bar stays inside its state box.
- `features/map/components/PlayButton.tsx` narrows its props to the button form of `Button`.
- The count tests change for the new files and controls: `hover.test.ts`, `bundle.test.ts`, `cards.test.ts`, `design.test.ts` and `scripts/__tests__/design-system.test.ts`. The last one also expects the new `Button` README forms.
- `BackLink` wraps its label in a `span`, so a long label ends in an ellipsis and does not wrap out of the 44px link.
- The `ActionBar` content is `layout.content-width` (1088px) wide, with the gutter outside it, so Save starts at the edge of the form column.
- `react-18.test.tsx` and the `Button` card get link states (`Button link`, `Button link secondary`) and a `NoticeCard · link action` state.
