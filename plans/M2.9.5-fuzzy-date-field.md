# Plan: M2.9.5: Fuzzy date: reading, messages and field

- **Spec:** #799
- **Requirement IDs:** [PIN-04](../docs/requirements.md#pin-04)
- **Status:** draft

## Approach

`lib/domain/dates/fuzzy-date-text.mts` exports `readFuzzyDate(date)` and `fuzzyDateMessage(error, text)`. The message function parses the text parts again with the exported `parseDate` and `daysIn` of `fuzzy-date.mts`. `reversed` gives `formatFuzzyDate(fuzzyDateOf(qualifier, date2, date1))`. The full month names move from `lib/domain/map/date-input.mts` to `lib/domain/dates/months.mts`.

`FuzzyDateField` (D1) takes the `TextField` box looks with `composes`, as `TextAreaField` does. Its input uses the D2 tokens, ligatures off. Enter and blur check the text. An error marks the box as `TextField` does and stays until the next check. As in `DateField`, the first render checks a `defaultValue`, unless `state` is `focus`. The kit error state uses this.

## Decisions

**D1 · The folder of `FuzzyDateField`** · Decides: Tech lead

The field imports `lib/domain`, which `app/components/` may not import (`scripts/layers.mts`). A canvas card gives a function prop a no-op only.

- **A.** `features/people/components/`, as `DateField` in `features/map`. A Pin form in another feature cannot import it, so a later Spec moves it.
- **B.** `app/components/forms/`. The layer table lets `kit` import `domain` (`scripts/layers.mts`, `docs/architecture.md`).
- **Other:** your own.

Recommended: A, because it keeps the layer rule and follows `DateField`.

**D2 · The token for 15/22 Mono** · Decides: Tech lead

- **A.** `type.mono-m` (15/22 · 400) and `type.mono-m-phone` (16/24 · 400), as `h1` and `h1-phone`. The 400 follows the `Fuzzy-date-readings` inputs.
- **B.** `type.mono-m` only. A phone takes the size and line of `type.body-l`.
- **Other:** your own.

Recommended: A, because the phone size then has its own token, as Spec D2 says.

**D3 · Empty text at a check** · Decides: Tech lead

- **A.** No error. The helper shows.
- **B.** The `syntax` message.
- **Other:** your own.

Recommended: A, because PPL-01 dates are optional, and the M2.9.9 Death helper says "Leave it empty if you don't know."
