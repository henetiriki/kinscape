## Approach

`lib/domain/dates/fuzzy-date-text.mts` exports `readFuzzyDate(date)` and `fuzzyDateMessage(error, text)`. The message function parses the text parts again with the exported `parseDate` and `daysIn` of `fuzzy-date.mts`. `reversed` gives `formatFuzzyDate(fuzzyDateOf(qualifier, date2, date1))`. The full month names move from `lib/domain/map/date-input.mts` to `lib/domain/dates/months.mts`.

`FuzzyDateField` (D1) takes the `TextField` box looks with `composes`, as `TextAreaField` does. Enter and blur check the text. An error marks the box as `TextField` does and stays until the next check. As in `DateField`, the first render checks a `defaultValue`, unless `state` is `focus`.

## Deviations

- `fuzzy-date.mts` also exports `splitFuzzyDate`, which `parseFuzzyDate` and the message function share. One function splits the text.
- The kit draws the typing, focus and error states `inert`, as the other state looks are. A 2px border leaves the input 42px tall, and `e2e/inputs.spec.ts` checks a 44px target.
- The line under the box is a `<p>` (20px). A `<span>` in a plain `div` made each field 1px taller than the board. The reading has a `.reading` style: 600 weight in `--ink`, as the `Fuzzy-date-readings` board draws it.
- The swap changes two things on purpose, and the tech lead accepted both. The text of a filled box goes from `#000000` to `--ink`. The error icon sits 13px from the right edge, as `TextField` draws it, and not 12px.
- "Try it" on `Fuzzy-date-readings` stays hand-drawn. The real field has no hook for its script (Risks).
- The `FuzzyDateField` card height (720) is a guess.
- After the review, the tech lead chose two guards for the field. Enter calls `preventDefault` for a date that fails the check, so a form does not submit it. The error is a new element at each check, so a screen reader reads a repeat. Day 0 gets the `syntax` message.
- `SG-Inputs` and `SG-Inputs-phone` are taller than the canvas draws (8000px), as on `main`: D4.
- The React 18 and 19 row of `docs/architecture.md` names `FuzzyDateField`.

## Risks

- **"Try it".** A board script drives the field on `Fuzzy-date-readings`. If the real field cannot take that script, step 7 swaps the states only.
